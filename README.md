**Що не вийшло або забрало найбільше часу:**

- Усунення помилок синтаксису C# при написанні скрипту (запобігання помилкам успадкування від `MonoBehaviour`)[cite: 1].

**Що зрозуміли про Update і Time.deltaTime:**
- Метод `Update()` викликається рушієм кожного кадру, тому без прив'язки до часу швидкість гри залежить від потужності ПК та частоти кадрів (FPS)[cite: 1].
- `Time.deltaTime` показує час у секундах, що минув між попереднім і поточним кадрами[cite: 1].
- Множення вектора руху на `Time.deltaTime` переводить розрахунок із «одиниць за кадр» в «одиниці за секунду», забезпечуючи однакову швидкість руху персонажа на будь-якому комп'ютері[cite: 1].
