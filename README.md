**Що не вийшло або забрало найбільше часу:**
- Пошук потрібних полів у Inspector (зокрема `Default Sprite` для `Rule Tile` та налаштувань імпорту текстур).
- Усунення помилок синтаксису C# при написанні скрипту (запобігання помилкам успадкування від `MonoBehaviour`).
- Освоєння інструментів малювання та перемикання плиток у вікні `Tile Palette`.

**Що зрозуміли про Update і Time.deltaTime:**
- Метод `Update()` викликається рушієм кожного кадру, тому без прив'язки до часу швидкість гри залежить від потужності ПК та частоти кадрів (FPS).
- `Time.deltaTime` показує час у секундах, що минув між попереднім і поточним кадрами.
- Множення вектора руху на `Time.deltaTime` переводить розрахунок із «одиниць за кадр» в «одиниці за секунду», забезпечуючи однакову швидкість руху персонажа на будь-якому комп'ютері.
