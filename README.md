**Що не вийшло або забрало найбільше часу:**
Найбільше часу пішло на правильне налаштування сортування шарів за віссю Y (щоб робот адекватно заходив за ящики й виходив перед ними) та на пошук причини тремтіння робота біля перешкод, яке виникало через пряме зміщення `transform.position` усередині `Update`.

**Що зрозумів про FixedUpdate і колайдери:**
* `Update()` викликається щокадру і слугує для зчитування вводу з клавіатури, тоді як `FixedUpdate()` працює з фіксованим часовим кроком фізичного рушія (50 разів на секунду) і призначений для фізичних обчислень.
* Зміна `transform.position` телепортує об'єкт в обхід фізики безпосередньо всередину колайдера, після чого рушій виштовхує його назад — це і є причиною тремтіння. Метод `MovePosition()` переміщує фізичне тіло за допомогою рушія з урахуванням зіткнень.
* Для тайлів підлоги обов'язково встановлюється `Collider Type = None`, інакше гравець застрягатиме на кожній плитці. `Composite Collider 2D` з операцією `Merge` об'єднує окремі колайдери тайлів води в один суцільний контур без відчутних стиків.

Розташування деяких декорацій та водойми довелося трохи змінити порівняно з початковим планом, щоб залишити достатньо ширини для вільного проходу персонажа й уникнути занадто вузьких місць між колайдерами.
